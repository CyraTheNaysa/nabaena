2D Platformer game
Your objective is to get as much coin as possible while avoiding bombs (you'll get less coins!)
The game had simple features such as :
- Basic left,right,jump movement
- walking & being hurt animation
- bomb and coin spawner at random position
- Coin counter UI

Play the game's demo immediately from your website!
